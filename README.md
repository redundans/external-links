# External Links

![License](https://img.shields.io/badge/license-MIT-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/redundans/external-links.svg)](https://packagist.org/packages/redundans/external-links) [![Total Downloads](https://img.shields.io/packagist/dt/redundans/external-links.svg)](https://packagist.org/packages/redundans/external-links)

A [Flarum](https://flarum.org) extension. Show links under tags in left column.

## Installation

Install with composer:

```sh
composer require redundans/external-links:"*"
```

## Updating

```sh
composer update redundans/external-links:"*"
php flarum migrate
php flarum cache:clear
```
